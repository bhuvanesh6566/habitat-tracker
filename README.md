## About

Habitat Tracker provides a software foundation for collecting, organizing, and tracking habitat-related information. The repository is maintained as a project prototype and can be extended with richer data management, visualization, filtering, and reporting capabilities.

## Features

- ✅ Habitat information tracking
- ✅ Structured project data
- ✅ Extensible foundation for future features
